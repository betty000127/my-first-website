# Betty 的第一個網站

繁體中文個人網站起點，採用純 HTML 與 CSS，支援手機、平板與桌面。不需要安裝套件或建置。

## 本機開發

在儲存庫目錄執行：

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

透過本機瀏覽器的 8000 連接埠瀏覽。按 Ctrl+C 停止伺服器。

## 修改內容

- `index.html`：網站文字、導覽與區塊。
- `styles.css`：顏色、字體、排版與響應式樣式。

首頁中的介紹文字是起始範例，可換成自己的內容。所有資源都存放於專案內，沒有外部字型或 API 依賴。

## 部署

可使用任何靜態網站主機。若使用 GitHub Pages，在儲存庫 Settings → Pages 選擇要發布的分支與根目錄，再儲存。此專案尚未自動部署。
